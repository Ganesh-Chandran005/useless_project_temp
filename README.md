# Oru Manga Eru Aparatha 🥭 🎯

## Basic Details
### Team Name: Melo Mates

### Team Members
- Team Lead: Ganesh Chandran - SJCET Palai

### Project Description
A highly accurate, nostalgic physics simulator built to recreate the childhood joy of plucking mangoes with a slingshot. It features real-time SVG rubber band tension, custom CSS environments, and absolutely zero respect for the user's heart rate. 

### The Problem (that doesn't exist)
Engineering students lack a safe, virtual environment to practice the ancient Kerala martial art of stealing the neighbor's mangoes without getting caught and yelled at by an angry aunty.

### The Solution (that nobody asked for)
We built a beautiful 2D drag-and-shoot game that lulls the user into a false sense of security. It uses slow, graceful cubic-bezier projectile physics to make the user think they are playing *Angry Birds*, before violently breaking the fourth wall, shattering their screen, and screaming at them in Malayalam.
